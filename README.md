
# Quick Install
To use it:
```shell
pip install graphpype
```

To develop:
```shell
git clone https://github.com/neuropycon/graphpype.git
cd macapype
python setup.py develop
```

# Docker image
```shell
docker pull macatools/graphpype:latest
```
